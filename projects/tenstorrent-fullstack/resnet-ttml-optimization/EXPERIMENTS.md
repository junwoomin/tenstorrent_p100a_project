# ResNet 최적화 실험 기록

## 기준 실험

사용자 보고 baseline은 약 **9.5 ms**이며 `x(1).zip`의 Python 20개를 현재 baseline으로 사용한다. **55 W**는 기존 보고값으로, 교체본의 신규 전력 측정값은 제공되지 않았다. 상세 실행 로그가 없어 모델 깊이, 측정 구간 및 학습·검증 구분은 확정하지 않는다. 현재 코드 기본값은 README에 별도로 기록하였다.

## 분석 원칙

동일 입력과 측정 범위에서 baseline과 변경본을 비교한다. 가능한 경우 하나의 설정만 변경하고, 결합 변경은 함께 표시한다. 레이어별 Conv, residual add, Pool 및 메모리 변환 시간을 확인하여 병목 후보를 구분한다. 메모리 이동 감소나 특정 하드웨어 병목은 프로파일 근거가 확보되기 전까지 가설로 기술한다.
