# ResNet 최적화 실험 기록

## 기준 실험

현재 baseline은 `x(2).zip`의 주석 제거 Python 10개이다. TTNN에서 backbone 가중치를 무작위 초기화한 뒤 고정하고 분류기만 학습한다. 새 코드의 성능 결과는 아직 제공되지 않았다.

이전 `x(1).zip`의 사용자 보고 지연시간 **9.5 ms** 및 기존 전력 보고 **55 W**는 과거 이력으로 보존한다. 새 baseline의 결과로 재사용하지 않는다.

## 분석 원칙

동일 입력과 측정 범위에서 baseline과 변경본을 비교한다. 가능한 경우 하나의 설정만 변경하고, 결합 변경은 함께 표시한다. 레이어별 Conv, residual add, Pool 및 메모리 변환 시간을 확인하여 병목 후보를 구분한다. 메모리 이동 감소나 특정 하드웨어 병목은 프로파일 근거가 확보되기 전까지 가설로 기술한다.
